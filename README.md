# 簿記2級 学習アプリ

日商簿記2級の学習をサポートするPWA。

## ローカル起動

```bash
python -m http.server 8000 --bind 127.0.0.1
```

その後、ブラウザで以下にアクセス:
- アプリ: http://127.0.0.1:8000/
- テスト: http://127.0.0.1:8000/test/

## 同期手順

### エクスポート（アプリ→バックアップ）
アプリの設定メニューからデータをエクスポートします。

### インポート（バックアップ→アプリ）
エクスポートしたファイルを読み込んでインポートします。
