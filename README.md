# 簿記2級 学習アプリ

日商簿記2級の学習をサポートする個人用PWA（PC・スマホ両対応、オフライン動作）。

## 公開URL

https://tnkl803-dev.github.io/boki-app/

（テスト: https://tnkl803-dev.github.io/boki-app/test/ → `fail 0` を確認）

## 使い方

### 初回
1. PC・スマホのブラウザで公開URLを開く（初期データ：カード20枚・問題16問が自動で入る）。
2. スマホは「ホーム画面に追加」（iPhone: Safari 共有→ホーム画面に追加／Android: Chrome メニュー→アプリをインストール）。以後オフラインでも起動可。
3. 「管理 → 設定・データ」で学習開始日・試験日・目標点・平日/休日の学習分を設定。

### 毎日の流れ
| タブ | すること |
|---|---|
| ホーム | 今日の期限カード数、今週の学習時間・正答率、今週のロードマップを確認 |
| 復習 | 「復習開始」→ 問題を見て考える →「答えを見る」→ 4段階で自己評価。一部しか答えられなかったら「できなかった」。評価に応じて次回出題日が自動で決まる |
| 演習 | 仕訳入力・勘定科目判断・計算などを選んで解く（1回10問まで、標準時間タイマー付き）。間違えたら原因を選ぶ |
| 記録 | 復習・演習の結果は日次記録に自動保存。週ごとの実績分・正答率を確認。通勤学習などは「＋手動追加」 |
| 管理 | カード・問題の追加/編集、ロードマップ確認、設定、データのエクスポート/インポート |

正答率は 正解÷(正解+不正解)。データが無いときは「データ不足」と表示。

## PC⇔スマホ同期（手動）
データは各端末のブラウザ内に保存される（サーバには送られない）。
1. 送る側：「管理 → 設定・データ → エクスポート」で JSON をダウンロード。
2. ファイルをもう一方の端末へ移す（OneDrive・メール添付など）。
3. 受ける側：「インポート」で JSON を選択。
   - **マージ（新しい方優先）**：通常はこちら。同じデータは更新が新しい方を残す。
   - **上書き（全置換）**：受ける側を丸ごと置き換える（バックアップ復元用）。取り込み前に現在のデータが自動でダウンロードされる。

注意：
- 削除は同期されない（別端末のファイルを取り込むと削除したものが戻る）。
- 同じ日に両端末でカードを新規作成し、同期前だった場合、取り込みで片方が消えることがある。カード追加はなるべく片方の端末で。
- ブラウザの「サイトデータ削除」をすると消えるので、週1回はエクスポートしておく。

## ローカル起動（開発用）

```bash
python -m http.server 8000 --bind 127.0.0.1
```

- アプリ: http://127.0.0.1:8000/
- テスト: http://127.0.0.1:8000/test/（ヘッドレス: `bash tools/run-tests.sh`）
- Excel から初期データ再生成: `python tools/excel_to_seed.py <xlsxのコピー> [出力先]`（xlsx は先に $TEMP へコピー）
